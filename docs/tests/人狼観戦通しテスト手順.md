# 人狼観戦 通しテスト手順

## 目的

任意ログからの追っかけ実況、再生時点盤面、リアルタイム合流、リアルタイムでの人狼卓1手進行、推理観戦／神視点観戦の情報境界を利用者操作で確認する。

## 前提

1. AI管理で観戦に使用するAIプロファイルを設定する。
2. 複数の公開ログ、処刑または朝の死亡、COまたは公開能力結果を含むゲームを用意する。
3. 可能なら訂正済み公開ログを1件含むゲームも用意する。
4. チャットルーム画面で「人狼観戦」を選択する。

## 1. 任意ログから追っかけ開始

1. 最新公開ログ番号を確認する。
2. 最新より十分前の存在する番号を「実況開始ログ番号」へ入力する。
3. 推理観戦で開始する。
4. 開始直後に指定ログ以降が一括表示されていないことを確認する。
5. 状態表示が「追っかけ」になり、次に再生するログ番号が指定番号になっていることを確認する。
6. 「人狼卓を1手進める」を1回押し、公開ログが1件だけ進むことを確認する。
7. 実際の人狼卓そのものの進行位置が変化していないことを確認する。

## 2. 欠番から開始

1. 公開ログsequenceに欠番があるゲームを用意する。
2. 欠番を実況開始ログ番号へ指定する。
3. 指定番号以上で最初に存在する公開ログが次ログとして選ばれることを確認する。

## 3. 未来番号から開始

1. 現在の最新公開ログより大きな番号を指定する。
2. 観戦を開始する。
3. 追っかけ表示を経ず「● リアルタイム」になることを確認する。
4. 公開盤面見出しが「現在の公開盤面」になることを確認する。

## 4. 再生時点のプレイヤー状態

1. 処刑または朝の死亡より前のログから追っかけを開始する。
2. 対象者が死亡するログへ到達する前は生存として表示されることを確認する。
3. 1ログずつ進め、死亡が公開されるログへ到達する。
4. その時点から死亡表示へ変化することを確認する。
5. CO、公開能力結果も該当ログ到達前には未来分が表示されず、到達後にだけ追加されることを確認する。

## 5. 訂正の時系列

1. 後から訂正された公開ログより前から追っかけを開始する。
2. 元ログへ到達した時点では、当時公開されていた内容として表示されることを確認する。
3. 訂正ログへ到達するまで元情報が時系列上維持されることを確認する。
4. 訂正ログ到達後に訂正後の公開状態へ変わることを確認する。

## 6. 追っかけ中に実卓が進行した場合

1. 追っかけ途中で再生位置を記録する。
2. AI管理側など別入口から人狼卓を進め、新しい公開ログを追加する。
3. 観戦画面の再生位置が勝手に進まないことを確認する。
4. 最新ログ番号だけが新しい位置へ更新されることを確認する。

## 7. リアルタイムへ移動

1. 複数ログを残した追っかけ状態にする。
2. 「リアルタイムへ移動」を押す。
3. 残りログが1件ずつ実況されず、最新地点へ直接移動することを確認する。
4. 「● リアルタイム」へ切り替わることを確認する。
5. スキップしたログへの観戦AIコメントが後からまとめて生成されないことを確認する。
6. 同じ位置のボタン名が「公開表示を再同期」になることを確認する。

## 8. 最新到達による自動合流

1. 最新ログの1件前まで追っかけを進める。
2. 「人狼卓を1手進める」で最後の公開ログを再生する。
3. 自動的に「● リアルタイム」へ変わることを確認する。
4. 以後、新規公開ログが発生した場合に既存のリアルタイム実況として扱われることを確認する。

## 9. リアルタイムでの人狼卓1手進行

1. リアルタイム状態で「人狼卓を1手進める」を1回押す。
2. AI管理の「1手実行」と同じ規則で人狼卓が1ステップだけ進むことを確認する。
3. 非公開処理だけのステップでは公開ログが増えない場合があることを確認する。
4. 人間入力待ち、手動AI待ち、実行ロック時はAI管理側と同じ制約・案内になることを確認する。

## 10. 観戦コメント自動生成

1. 追っかけ状態で「観戦コメントを自動生成」をONにする。
2. 何も操作せず待ち、再生ログが勝手に進まないことを確認する。
3. 「人狼卓を1手進める」で公開ログを1件表示する。
4. 表示したログへの観戦AI反応だけが自動生成されることを確認する。

## 11. 推理観戦の情報境界

1. 未来に死亡・CO・公開能力結果がある地点より前から推理観戦を開始する。
2. 画面および観戦AI発言に未来の状態が混入しないことを確認する。
3. 最新ログ番号や残り未再生件数を根拠に未来を知ったようなAI用データが表示・生成されていないことを確認する。

## 12. 神視点観戦

1. 同じゲームで神視点観戦を開始する。
2. 真役職が表示されることを確認する。
3. 生死は再生地点の状態と一致することを確認する。
4. 座敷わらしなど遅延所属がある場合、所属確定前の再生地点では「所属未確定」、確定後に現在陣営が表示されることを確認する。

## 13. 保存・再起動

1. 追っかけ途中でアプリを終了する。
2. 再起動して人狼観戦を開く。
3. 最新観戦セッションと再生位置が復元されることを確認する。
4. 自由会話セッション、ゲーム自動保存と観戦セッションが混在していないことを確認する。
